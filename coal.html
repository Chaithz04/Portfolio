Coal & Lignite Production Analytics Dashboard

Power BI • Interactive Dashboard • Mining Analytics

Project Overview


The Coal & Lignite Production Analytics Dashboard is an interactive Power BI project developed to analyze coal and lignite production across India. The dashboard presents production statistics, mining operations, ownership patterns and regional performance using interactive visualizations that support quick analysis and informed decision-making.

Project Objective

  • Analyze overall coal and lignite production.
  • Compare coal production with lignite production.
  • Study mining operations across India.
  • Identify top producing states and mines.
  • Analyze ownership patterns.
  • Provide regional insights through interactive dashboards.

Skills Demonstrated

📊 Dashboard Design

Designed an interactive multi-page Power BI dashboard using a consistent mining-themed layout.

📈 Data Visualization

Created meaningful visualizations to compare production, ownership and mine performance.

📋 KPI Development

Developed KPI cards to summarize production, number of mines and mining categories.

📍 Interactive Reporting

Designed multiple dashboard pages allowing users to explore production statistics efficiently.

📉 Business Insight Generation

Analyzed production trends, ownership distribution and regional performance.

📖 Data Storytelling

Presented mining statistics through a structured dashboard that guides users from overview to detailed analysis.

Dashboard 1 : Production Overview


Overview


The first dashboard provides an overall summary of coal and lignite production in India. It combines key production metrics, production comparison charts and dataset highlights to give users a quick understanding of the mining industry.


Key Performance Indicators (KPIs)


  • Total Production (773.47 Million Tonnes) – Total coal and lignite production during the selected period.
  • Total Mines (459) – Total operational coal and lignite mines.
  • Coal Mines (440) – Number of coal mines.
  • Lignite Mines (19) – Number of lignite mines.

Visualizations Used


📊 Coal vs Lignite Production

The donut chart compares coal and lignite production, highlighting that coal contributes the overwhelming majority of total production.


📋 Dataset Highlights

KPI cards provide an instant summary of production, mine count and mining categories.

Key Insights

  • Coal accounts for the majority of India's mineral fuel production.
  • Lignite contributes only a small percentage of total production.
  • Coal mines significantly outnumber lignite mines.
  • The dashboard provides a quick snapshot of India's mining sector.

Dashboard 2 : Production Analysis


Overview


This dashboard focuses on production trends across different states, ownership categories and mine types. It enables users to identify top-producing regions and understand production distribution within the mining sector.


Dashboard Highlights


  • State-wise production comparison.
  • Top five producing mines.
  • Production based on ownership.
  • Production by mine type.

Visualizations Explained


📊 State-wise Production

The column chart compares production across different states, helping identify major contributors.


🏆 Top Producing Mines

The treemap highlights the highest-producing mines, allowing easy comparison of their contribution.


🏢 Ownership Analysis

The horizontal bar chart compares production by Government, State Government and Private ownership.


⛏ Mine Type Distribution

The donut chart compares production from Open Cast, Underground and Mixed mines.


Insights


  • Chhattisgarh is one of the leading coal-producing states.
  • Government-owned mines contribute the highest production.
  • Open Cast mines dominate overall production.
  • A few mines contribute a significant share of total production.

Dashboard 3 : Mining Operations


Overview


This dashboard focuses on mining operations by analyzing mine types, mine ownership and production contribution from major mining companies. It helps users understand operational efficiency and production distribution across mining sectors.


Dashboard Highlights


  • Number of Open Cast, Underground and Mixed mines.
  • Top six mine owners based on production.
  • Mine type comparison.
  • Production contribution by ownership.

Visualizations Explained


⛏ Mine Type Analysis

The horizontal bar chart compares the number of Open Cast, Underground and Mixed mines operating across India.


🏭 Top Mine Owners

The column chart highlights the top six mining companies contributing the highest production.


📊 KPI Cards

KPI cards summarize the number of Open Cast, Underground and Mixed mines for quick reference.


Key Insights


  • Open Cast mines represent the largest mining category.
  • Underground mines are fewer but remain operational in several regions.
  • South Eastern Coalfields Limited recorded the highest production.
  • A small number of companies contribute a major share of production.

Dashboard 4 : Regional Insights


Overview


The Regional Insights dashboard presents the geographical distribution of coal production across India using an interactive map visualization. It enables users to identify leading coal-producing states and understand regional production patterns.


Dashboard Highlights


  • Interactive geographical map.
  • Top producing states.
  • Production represented using proportional bubbles.
  • Easy regional comparison.

Insights


  • Production is concentrated in a few major states.
  • Eastern and Central India dominate coal production.
  • The map provides an intuitive understanding of regional distribution.
  • Interactive geographic visualization improves decision-making.

Business Value

This dashboard enables government agencies, mining companies and industry analysts to monitor production trends, compare operational performance and identify key mining regions through interactive visualizations.


The dashboard transforms raw mining data into meaningful business insights that support production planning, operational analysis and strategic decision-making.
