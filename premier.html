Premier League Match Analytics Dashboard

Power BI • Interactive Dashboard • Data Visualization

Project Overview


This interactive Power BI dashboard was developed to analyze the English Premier League 2021–22 season using match statistics, club performance, disciplinary records and goal analysis. The dashboard transforms raw football data into meaningful visual insights through interactive reports and KPIs.

Project Objective

  • Analyze overall league performance.
  • Compare home wins, away wins and draws.
  • Study monthly goal scoring trends.
  • Analyze club performance throughout the season.
  • Visualize player discipline through yellow and red cards.
  • Create an interactive dashboard for easy decision making.

Used charts, KPI cards and visual elements to present complex football statistics in a simple and engaging way.

📋 KPI Development

Dashboard 1 : Season Overview


Overview


The Overview Dashboard provides a high-level summary of the Premier League 2021–22 season. It presents key performance indicators (KPIs) and visualizations that allow users to quickly understand overall league performance.


Key Performance Indicators (KPIs)


  • Total Matches (380) – Displays the total number of league matches played during the season.
  • Total Clubs (20) – Shows the number of participating clubs.
  • Total Red Cards (43) – Highlights disciplinary actions throughout the season.
  • Home Wins (163) – Indicates the number of matches won by home teams.
  • Away Wins (129) – Indicates the number of matches won by away teams.

Visualizations Used


📊 Donut Chart

The donut chart compares Home Wins, Draws, and Away Wins, making it easy to understand the distribution of match outcomes across the season.


📈 Monthly Goals Trend

The line chart visualizes total goals scored each month, helping identify periods with high and low scoring matches.


📋 Goals Summary Cards

KPI cards display Total Goals, Home Goals and Away Goals, allowing quick comparison between overall scoring statistics.

Key Insights

  • Home teams recorded more victories than away teams.
  • December 2021 experienced the highest number of goals scored.
  • Home goals slightly exceeded away goals during the season.
  • The league maintained consistent scoring throughout most months.
  • The dashboard enables quick understanding of overall season performance through interactive KPIs.

Dashboard 2 : Team Performance Analysis


Overview


This dashboard focuses on team performance across the Premier League season. It compares clubs using various performance metrics, enabling users to identify the strongest teams and analyze consistency throughout the competition.


Dashboard Highlights


  • Comparison of clubs based on points and wins.
  • Goals scored and goals conceded analysis.
  • Home and away performance comparison.
  • Interactive club filtering.
  • Performance ranking using visual charts.

Insights


  • Top-performing clubs maintained consistent winning records.
  • Some clubs performed significantly better at home than away.
  • Goal difference strongly influenced final league standings.

Dashboard 3 : Discipline & Action Analysis


Overview


This dashboard analyzes player discipline by tracking yellow cards, red cards, fouls and overall disciplinary actions throughout the season.


Dashboard Highlights


  • Total Yellow Cards.
  • Total Red Cards.
  • Cards received by each club.
  • Comparison of disciplinary records.
  • Interactive filtering for detailed analysis.

Insights


  • Only a few clubs accumulated a high number of red cards.
  • Yellow cards were significantly more frequent than red cards.
  • Discipline varied noticeably among teams.

Business Value

This dashboard enables sports analysts, coaches and football enthusiasts to quickly evaluate club performance, monitor goal trends and understand disciplinary statistics using interactive visualizations.


By transforming raw match data into meaningful insights, decision-makers can compare teams, identify strengths and weaknesses and analyze seasonal performance efficiently.
